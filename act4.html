  • CPNT (.Net)
  1. Lesson 1: Fundamentals of HTML
  1. Summary: HTML (HyperText Markup Language) is the standard markup language used to create the structure of web pages. It uses different elements and tags to organize content such as text, images, links, tables, and forms.
  2. Reflection: This lesson helped me understand that HTML is the foundation of every website. Learning the basic structure of HTML made it easier for me to appreciate how web pages are created.
  3. Application: I can create a basic webpage by applying HTML tags to display organized and meaningful content.
  1. Lesson 2: Block Level Elements
  1. Summary: Block-level elements occupy the entire width of a webpage and automatically begin on a new line. They are commonly used to organize different sections of a webpage.
  2. Reflection: I realized that using block-level elements makes webpages more organized, readable, and easier to maintain.
  3. Application: I can use elements such as alt;div,h1, p, and <section> to structure a webpage properly.
  1. Lesson 3: HTML Attributes
  1. Summary: HTML attributes provide additional information about HTML elements. They define properties such as links, image sources, styles, identifiers, and classes.
  2. Reflection: This lesson taught me that attributes improve the functionality and appearance of a webpage while making elements more flexible.
  3. Application: I can apply attributes like href, src, alt, id, class, and style to enhance web page features.
  1. Lesson 4: Apply List Attributes and Value in Web Page Designs
  1. Summary: HTML lists can be customized using attributes such as type, value, and start to organize information using different numbering and bullet styles.
  2. Reflection: I learned that properly formatted lists improve the readability and organization of webpage content.
  3. Application: I can create ordered and unordered lists for menus, instructions, outlines, and lesson topics.

  3. Application: I can analyze activities such as riding a bicycle, kicking a ball, or driving a vehicle using Newton's Laws.
